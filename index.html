Projects

agent-skills

Open source

Portable Claude Code skills for PR preflight, code review, security review and dependency hygiene, plus a CLI that vendors them into a repo under a hash-locked manifest and flags drift in CI. Reviews run in a fresh session, so the author is never the reviewer.

agent-ci-kit

Open source

A kit you copy into a repo so Claude Code agents fix labeled GitHub issues from Actions and open draft PRs. Its limits live in the workflows rather than the prompt: shell access is an allowlist read from the default branch, web tools are off, the fix workflow won't open a PR that touches CI, agent config or .env files, and merging is left to a human. Every run has turn and time caps, and issue fixes have a daily cap.

chuck

Open source

A Go control plane I'm building to move GitHub issues through build, review, merge, validation and production promotion. Each stage is designed to run as a fresh Claude Code worker on an ephemeral machine. Agents report and code decides: by design, workers hold no merge rights and no model credentials.
